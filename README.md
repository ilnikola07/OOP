## Лабораторные работы №1 и №2 

Работы представляют собой единое десктопное приложение на базе **WPF**, включая в себя архитектуру **MVVM** и отдельную библиотеку ресурсов.

### Лабораторная работа №1. Построение интерфейса в WPF
* **Цель:** изучить основные элементы подсистемы WPF для построения интерфейса приложения.

**Реализованный функционал (вкладки `TabControl`):**
1. **Основное**:
   * сгруппированные настройки персонализации (выбор темы и языка приложения через `ComboBox`);
   * сгруппированные настройки шрифтов (выбор шрифта через `ComboBox` и размера шрифта через `Slider`).
2. **Цветовая палитра**:
   * отображение названия текущей темы;
   * сгруппированные цвета: основной, акцентный и индикаторные (*Успех*, *Ошибка*, *Информация*);
   * таблицы оттенков (по 10 градаций: цвет / RGB-код / наименование) для каждого базового цвета.
3. **Элементы управления** (сгруппированы по распахиваемым контейнерам `Expander` с отображением состояний *Default*, *Pressed*, *Loading*, *Disabled* и стилей *Primary*, *Secondary*, *Tertiary* для каждой цветовой группы):
   * кнопки (обычные, пиктограммы, переключатели);
   * списки и поля ввода (`ListBox`, `ComboBox`, `TextBox`, `PasswordBox`, `RichTextBox`);
   * текстовые элементы (`TextBlock`, `Label` — заголовки 1–3 уровней, обычный текст, подписи);
   * иерархические списки и таблицы (`TreeView`, `DataGrid`);
   * индикаторы выполнения (`ProgressBar`);
   * всплывающие подсказки (`ToolTip`), главное меню (`Menu`) и контекстное меню (`ContextMenu`).
4. **Контейнеры компоновки**:
   * наглядная демонстрация работы различных панелей компоновки (`Grid`, `StackPanel`, `WrapPanel`, `DockPanel`, `Canvas` и др.) на примере стилизованных в тему приложения прямоугольников.

### Лабораторная работа №2. Привязки и MVVM
* **Цель:** изучить концепции WPF и перевести приложение из ЛР №1 на полноценную рабочую логику.

**Реализованный функционал:**
* **Архитектура и стили:**
  * приложение переведено на паттерн **MVVM** с использованием интерфейса `INotifyPropertyChanged`;
  * вынесена отдельная библиотека ресурсов (Resource Dictionary) в самостоятельный проект, стили из ЛР №1 переведены на её использование;
  * проект подключён к системе контроля версий Git.
* **Оживление интерфейса (Bindings & Commands):**
  * реализована динамическая смена тем, языков, шрифта и его размера из вкладки «Основное» с помощью привязок и команд.
* **Работа с таблицами (`DataGrid`):**
  * реализовано добавление, редактирование и удаление записей в таблице;
  * на панель инструментов (`ToolBar`) добавлены кнопки **«Копировать»** и **«Вставить»**, позволяющие переносить данные из одной таблицы в другую через команды (`ICommand`).
* **Вкладка демонстрации привязок:**
  * добавлена отдельная вкладка, демонстрирующая все режимы привязки данных (`OneWay`, `TwoWay`, `OneTime`, `OneWayToSource`) и режимы обновления источника (`PropertyChanged`, `LostFocus`, `Explicit`).

## Проект промежуточной аттестации: «Автобусный парк»

**Модель данных (сведения о каждом автобусе):**
* номер автобуса;
* фамилия и инициалы водителя;
* номер маршрута.

**Функциональные требования (выбор через меню):**
1. **Начальное формирование данных:** создание списка всех автобусов в парке (поддержка ввода с клавиатуры или загрузки из файла).
2. **Имитация выезда автобуса из парка:**
   * ввод номера автобуса;
   * удаление данных об автобусе из списка *находящихся в парке*;
   * добавление этих данных в список *находящихся на маршруте*.
3. **Имитация въезда автобуса в парк:**
   * ввод номера автобуса;
   * удаление данных об автобусе из списка *находящихся на маршруте*;
   * возврат этих данных в список *находящихся в парке*.
4. **Вывод сведений:** отображение актуальных списков автобусов, находящихся в парке, и автобусов, находящихся на маршруте.

## Стек технологий и запуск

* **Язык:** C# (.NET)
* **UI-фреймворк:** Windows Presentation Foundation (WPF)
* **Среда разработки:** Visual Studio 2022 / JetBrains Rider

### Запуск проектов
1. Клонируйте репозиторий:
   ```bash
   git clone <URL_вашего_репозитория>
   ```
2. Откройте файл решения (`.sln`) в Visual Studio.
3. Выберите нужный стартовый проект (WPF-приложение для ЛР №1–2 или проект аттестации) и нажмите `F5`.
